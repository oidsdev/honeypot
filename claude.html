Working with Claude?

Claude does the reading and the checking: research, QA, the fine print. That means documents in, claims verified, findings written down. Here's what to plug in first.

Each one downloads with a single command (saves as its own file, no overwrites). Tell Claude to run it, or paste it into the terminal yourself.

pdf-text

The reading starts here. Hand Claude a PDF, get the text back: filings, papers, contracts, all searchable in seconds.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/pdf-text/SKILL.md -o pdf-text-SKILL.md

context7

Current docs for whatever library is in question, looked up live. No answering from a stale memory of an API.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/context7/SKILL.md -o context7-SKILL.md

Honeypot FAQ

What is Honeypot?

Honeypot is a free, open index of skills for AI agents. One machine-readable JSON file, per-category indexes, RSS for new skills. No sign-up, no tracking.

Where can I find AI agent skills?

Here. The full index is at /api/skills.json, with per-category feeds at /api/by-category/<category>.json. Skills are also discoverable through GitHub awesome-lists and the skills.sh directory.

Is Honeypot free?

Yes. Free, open source (MIT), tracking-free. No sign-up, no API key, no paid tier. It's a static site — nothing to bill you for, nothing tracking you.

How do I add my skill to Honeypot?

Open a pull request with your SKILL.md. Requirements: name and description frontmatter, one category, tags, a current last_verified date, MIT-compatible license. Full requirements are in the repo README.

How do I keep my copy of the index fresh?

Poll /api/changelog.json for changes, or subscribe to the RSS feed. The index includes a heartbeat skill that refreshes a local copy on a schedule.

What format is the index?

Versioned JSON (schema_version 1). Every entry carries name, description, category, tags, source URL, license, and last_verified.

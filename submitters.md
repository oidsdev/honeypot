# Honeypot submitters — contact log

Every skill submission is a qualified contact: someone who builds agent tooling.
Log them here, work them warm, never spam.

## How a submitter becomes an asset

1. **Thank + feature.** Merge fast, comment on the PR, add the skill to the "new" spotlight. Creators promote what features them — their announcement is our distribution.
2. **Invite to Oids.** One genuine line: they're already building in the open, Oids is where agents post playbooks. No blast DMs, no automation.
3. **Record the graph.** GitHub username → X handle / site / Oids username when given. These are the operators who ship; they're the recruiting pool for bounties, collabs, and later Oids Pro word-of-mouth.
4. **Read the demand.** Which categories get submitted tells us what agents actually need — that shapes what we build next (prompt packs, Oids features, products).

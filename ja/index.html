掲載基準

どのスキルも、プルリクエストを通して載ります。マージする前に、一つずつ読んでいます。

  • スパム、重複、悪意のあるものはクローズします。
  • ライセンスはMIT互換のみです。再配布できないものは索引に載せられません。
  • SKILL.mdのフロントマターには name と description が必要です。無いPRは差し戻します。

スキルを投稿する

  1. スキルは SKILL.md に書いてください。テンプレートから書き始められます。
  2. github.com/oidsdev/honeypot をフォークしてください。
  3. skills/<your-skill>/SKILL.md に追加してください。
  4. プルリクエストを開いてください。すぐマージします。
  5. 索引を見つけてもらえるよう、リポジトリにバッジを置いてください。
    [![Indexed on Honeypot](https://honeypot-e6c.pages.dev/badge.svg)](https://honeypot-e6c.pages.dev)
    スキル別バッジ（名前、バージョン、検証マーク）: /badge/<skill>.svg

任意です。PRの説明にOidsのユーザー名かXのハンドルを書くと、取り上げるときに名前を出します。

機械向け

全索引（JSON）: /api/skills.json
編集部ピックとチェックリスト: /api/editors-picks.json
追加されたスキル: /api/changelog.json と /feed.xml (RSS)
スキル別バッジ: /badge/<skill>.svg
カテゴリ別: /api/by-category/<category>.json (trading, data, identity, meta, tooling)
カテゴリページ: /categories/<category>/
エージェント向けの説明: /llms.txt
MCPサーバー（stdio、標準ライブラリのみ）: /mcp-server.py (tools: search_skills, get_skill, list_categories, get_editors_picks)
リンクできる検索: /?q=<text>&tag=<tag>&category=<category>（例: /?tag=prediction-markets）

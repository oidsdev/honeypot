Just got a Dot?

OpenAI's Dots are always-on agents. They remember things, work on a schedule, and use tools. A dot with no tools is just a chatbot that never sleeps. Start with these five.

Each one downloads with a single command (saves as its own file, no overwrites). Tell your dot to run it, or paste it into the dot's terminal yourself.

Start with these five

1. cron

Teaches your dot to run things on a schedule: morning briefings, weekly reports, reminders.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/cron/SKILL.md -o cron-SKILL.md

2. pdf-text

Hand your dot a PDF and get the text back: contracts, manuals, research papers, readable in seconds.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/pdf-text/SKILL.md -o pdf-text-SKILL.md

3. sqlite

A real database on the machine for trackers, lists, and logs, kept structured between sessions.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/sqlite/SKILL.md -o sqlite-SKILL.md

4. image-optimize

Shrinks images before upload. Smaller files, faster everything, originals untouched.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/image-optimize/SKILL.md -o image-optimize-SKILL.md

5. skill-creator

The skill for writing skills: package anything your dot learns into something reusable.

curl -sL https://raw.githubusercontent.com/oidsdev/honeypot/main/skills/skill-creator/SKILL.md -o skill-creator-SKILL.md

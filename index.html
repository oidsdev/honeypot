How we curate

Every skill gets in through a pull request, and we read each one before it merges.

  • Spam, duplicates, and anything malicious get closed.
  • MIT-compatible licenses only. We can't index what we can't redistribute.
  • The SKILL.md frontmatter needs a name and a description. PRs without them get bounced.

Submit a skill

  1. Write your skill as a SKILL.md. Start from the template.
  2. Fork github.com/oidsdev/honeypot.
  3. Add it at skills/<your-skill>/SKILL.md.
  4. Open a pull request. We merge fast.
  5. Add a badge to your repo so people find the index:
    [![Indexed on Honeypot](https://honeypot-e6c.pages.dev/badge.svg)](https://honeypot-e6c.pages.dev)
    Per-skill badge (name, version, verified check): /badge/<skill>.svg

Optional: put your Oids username or X handle in the PR description and we'll credit you when we feature it.
